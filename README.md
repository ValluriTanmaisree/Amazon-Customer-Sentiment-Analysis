# Amazon Sentiment Analysis using Power BI

Project Overview
This project focuses on analyzing Amazon customer reviews to understand customer opinions and sentiment patterns using Power BI. The dashboard presents meaningful insights through interactive visualizations and KPI cards.

 Objectives
- Analyze customer review data.
- Understand customer sentiment patterns.
- Identify useful insights from customer feedback.
- Present findings through an interactive dashboard.

 Tools & Technologies
- Power BI
- Power Query
- DAX

 Project Activities
- Data exploration and cleaning.
- Data transformation using Power Query.
- Data analysis using DAX.
- Creating KPI cards and interactive visualizations.
- Developing a dashboard to present insights.

 Project Files
- `amazon_sentiment_analysis.pdf` – Power BI dashboard report.
- `Amazon_sentiment_analysis.mp4` – Project demonstration video.
